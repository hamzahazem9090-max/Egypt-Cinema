# 🎬 Egypt Cinema

موقع مشاهدة الأفلام المترجمة اون لاين — واجهة عربية RTL داكنة تعتمد على بيانات TMDB والبحث عن مصدر البث على topcinema.io.

## الملفات

كل الملفات في مكان واحد من غير فولدرات:

| الملف | الوصف |
| --- | --- |
| `index.html` | الصفحة الرئيسية (الهيكل + الشريط العلوي) |
| `style.css` | الثيم والتصميم |
| `app.js` | كل المنطق: TMDB، بحث المصدر، المفضلة، التقييمات، آخر المشاهدة |

## المميزات

- الرئيسية: أفلام رائجة الأسبوع + أينما السينما + الأعلى تقييمًا + قريبًا
- تصفح جميع الأفلام مع فلاتر (النوع / السنة / الترتيب) وصفحات
- بحث فوري
- صفحة تفاصيل (مخرج، نجوم، إعلان، أفلام مشابهة)
- مشاهدة الفيلم عبر بلاير مدمج
- مفضلة / تقييم 5 نجوم / آخر المشاهدة (محفوظة محليًا في المتصفح)

> ملاحظة: لا يوجد خادم — البيانات واللكنات من المصدر، والمكتبة محفوظة في متصفحك (localStorage). في كل جهاز جديد تبدأ من الصفر.

## التشغيل محليًا

افتح `index.html` مباشرة في المتصفح (double-click) — الموقع هيشتغل وهيجلب الأفلام.

أو لو حابب serve عبر http محلي:

```powershell
npx serve .
```

## النشر على الإنترنت (مجاني، بدون كتابة كود)

**الطريقة 1 — Netlify Drop (الأسهل):**

1. افتح https://app.netlify.com/drop
2. اسحب المجلد كامل (اللي فيه `index.html`) وأفلته في المتصفح
3. يظهر لك رابط مباشر (مثل `https://top-cinema.netlify.app`) وانتهى

**الطريقة 2 — من GitHub (auto-updates):**

1. ارفع الملفات على ريبو GitHub
2. https://app.netlify.com → Add new site → Import from Git → اختر الريبو
3. Build command: فارغ — Publish directory: `.`
4. الأن Netlify بتبني تلقائي مع أي تحديث

## ملاحظة API

المفتاح الخاص بـ TMDB داخل `app.js` (شفرة القراءة فقط) — لو استنفدت حد الاستخدام المفتوح لكل عرض، تقدر تستبدله بمفتاحك من https://www.themoviedb.org/settings/api
